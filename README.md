# THERMOACOUSTIX
ThermoAcoustix is a low-cost automated vibration-based material screening prototype built by Team Voltage Mafia at Sensored Beyond X Hackathon (Gravitas Event conducted by VIT Vellore | TEC. It features an ESP32 central brain, a servo impact mechanism, an ADXL345 accelerometer, and FFT signal processing for edge-based anomaly and defect detection.
